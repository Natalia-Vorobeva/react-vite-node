## 🎯 О проекте

Это тестовое задание - мессенджер, который отображает сообщения в трех колонках (левая, центральная, правая). 
Приложение имитирует реальный мессенджер с возможностью фильтрации, поиска, перемещения сообщений между колонками и добавления в избранное.

### ✨ Возможности

- **Трехколоночный интерфейс**: сообщения распределены по трем колонкам (левая, центральная, правая).
- **Поиск**: поиск сообщений по содержимому во всех колонках.
- **Фильтрация**: отображение всех сообщений или только избранных.
- **Избранное**: возможность добавлять сообщения в избранное (лайк).
- **Перемещение**: перемещение сообщений между колонками с помощью кнопок.
- **Сортировка**: изменение порядка отображения (новые сверху / старые сверху).
- **Адаптивный дизайн**: на мобильных устройствах колонки переключаются табами.
- **Автообновление**: новые сообщения подгружаются автоматически каждые 5 секунд.
- **Загрузка старых сообщений**: кнопка для загрузки предыдущих сообщений.

## 🛠 Технологии

- **React** (с использованием функциональных компонентов и хуков)
- **Redux Toolkit** (для управления состоянием)
- **Vite** (для сборки)
- **SCSS** (для стилей)
- **Vercel** (для деплоя)

## 🌐 API

Приложение получает данные с внешнего сервера по протоколу HTTP. 
Все запросы отправляются на `http://a0830433.xsph.ru` (или через прокси в разработке).
